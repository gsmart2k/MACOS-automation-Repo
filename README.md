## Smart File Organizer

**Technology:** Apple Shortcuts | macOS

### Project Overview
Built a file organization shortcut that identifies selected files by their extensions and saves them into designated folders.

### Key Features
- Detects PDF documents and JPG/JPEG images.
- Saves PDF documents to a PDFs folder.
- Saves JPG and JPEG images to an Images folder.
- Uses conditional logic and file extension detection to route files.
- Reduces manual file sorting.

### Testing and Results
Successfully tested the shortcut with PDF and JPEG files. Both file types were saved to their intended folders.

### Skills Demonstrated
- Workflow automation
- Conditional logic
- File management
- Variable handling
- Debugging and troubleshooting
- Functional testing

## Smart Google Search

**Technology:** Apple Shortcuts, macOS

### Project Overview
Developed a macOS automation that simplifies Google searches by accepting user input, encoding search terms, and opening the corresponding search results in a web browser.

### Key Features
- Accepts search queries through a text prompt.
- Uses URL encoding to format search terms.
- Automatically generates Google search URLs.
- Opens search results in the browser.

### Skills Demonstrated
Workflow automation, user input handling, URL encoding, and productivity optimization.
